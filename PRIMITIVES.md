# Primitives

> Single inventory of this single-package project, in the project root. Status is `confirmed` when the implementation was read and `inferred` when only a reference or a usage was seen; `pending <branch>` follows the status while the code is not in the integration branch, `main`.

## image core

- **`RasterImage` / `Rect` / `Point` / `Rgba` / `Patch`**, `src/core/types.ts`, confirmed
  The pixel and geometry vocabulary that every core function, worker message and app module shares. Contract: `RasterImage { width; height; data: Uint8ClampedArray }`, `Rect { x; y; w; h }`, `Point { x; y }`, `Rgba { r; g; b; a }`, `Patch { rect: Rect; before: Uint8ClampedArray; after: Uint8ClampedArray }`. `RasterImage.data` is RGBA8, row-major, with straight alpha (not premultiplied), so it goes into an `ImageData` with no conversion. Each `Rgba` channel is 0..255, and the alpha is 0..255 too, not 0..1. `Rect` fields can be fractional, and the raster helpers round them. `Patch.rect` is in layer px, and `before` and `after` each hold `rect.w * rect.h * 4` bytes; [[PRIMITIVES#EditorDoc]] writes a patch with `commitPatch`. The feature types of this file (`ExportFormat`, `ExportOptions`, `ResampleMethod`, `AdjustOp` and its params, `Histogram`, `TextSpec`, `ShapeSpec`, `StrokeStyle`, `FrameParams`) belong to the entries that use them.
  Consumers: >=35 for `RasterImage`, >=26 for `Rect`, >=19 for `Point`, 18 for `Rgba`, 3 for `Patch` (`app/doc.svelte.ts`, `core/fill.ts`, `core/stroke.ts`).
- **`Mask` / `MaskOp`**, `src/core/mask.ts`, confirmed
  The selection: an anti-aliased coverage map at document size, with builders and boolean ops. Contract: `Mask { width; height; data: Uint8Array /* 0..255 */; bounds: Rect | null }`; `rectMask(w, h, r, feather = 0)`, `ellipseMask(w, h, r, feather = 0)`, `polygonMask(w, h, points: Float32Array /* x0,y0,x1,y1,... even-odd */, feather = 0)`, `maskFromData(w, h, data)`, `featherMask(mask, feather)`, `combineMask(a | null, b, op: 'replace' | 'add' | 'subtract' | 'intersect'): Mask | null`, `invertMask(m | null, w, h): Mask`, `translateMask(m, dx, dy, w, h): Mask | null`, `coverage(m | null, x, y): number`, `maskOutline(m): Float32Array[]`. A mask always has the document size, so a reader at layer px must add the layer offset. A `null` mask means "no selection, so everything": `coverage(null)` is 255 and `invertMask(null)` is empty. `combineMask` and `translateMask` return `null` for an empty result. `invertMask` can return an empty `Mask` (`bounds: null`), so callers check `bounds` before they store it. `maskFromData` wraps the buffer with no copy and computes `bounds` one time, so do not change `data` after the build. Feather is clamped to `PARAMS.mask.maxFeather`. `maskOutline` traces the coverage-128 contour in document px, as closed polylines.
  Consumers: 16 (`app/actions/select.ts`, `app/doc.svelte.ts`, `app/engine.ts`, tools `brush` (`coverage`, in [[PRIMITIVES#createStrokeTool]]), `bucket`, `lasso`, `marquee-rect`, `move`, `wand`, `core/adjust/common.ts`, `core/adjust/index.ts`, `core/fill.ts`, `core/protocol.ts`, `core/stroke.ts`, `ui/options/SelectOptions.svelte`, `ui/overlays/selection.ts`).
- **`createRaster` / `cloneRaster` / `cropRaster` / `blitRaster` / `readRect` / `writeRect` / `intersectRect` / `unionRect` / `opaqueBounds`**, `src/core/raster.ts`, confirmed
  The allocation, copy, clip and rect math helpers of `RasterImage`. Contract: `createRaster(w, h, fill?: Rgba)`, `cloneRaster(image)`, `cropRaster(image, r, fill?)`, `blitRaster(src, from: Rect, dst, dx, dy): void`, `readRect(image, r): Uint8ClampedArray`, `writeRect(image, r, data): void`, `intersectRect(a, b): Rect | null`, `unionRect(a | null, b): Rect`, `opaqueBounds(image): Rect | null`. All pixel ops round rects to whole px and clip them to both images. `cropRaster` and `readRect` can read outside the image: that part reads as `fill` (transparent by default). `writeRect` ignores the part outside the image, and it throws `RangeError` when `data` is shorter than `r.w * r.h * 4`. `blitRaster` copies bytes and does no blend: use [[PRIMITIVES#flatten]] for a composite. `opaqueBounds` counts each pixel with alpha > 0.

- **`decodePng` / `encodePng` / `pngSize` / `isPng`**, `src/core/png.ts`, confirmed
  The PNG codec of the project: it decodes exactly to RGBA8 and encodes plain PNG with no canvas. Contract: `decodePng(bytes: Uint8Array): RasterImage`; `encodePng(image): Uint8Array`; `pngSize(bytes): { width; height } | null` (read from IHDR); `isPng(bytes): boolean`. `decodePng` reads every color type and bit depth, and it uses `tRNS`. Sixteen-bit samples become 8-bit. Gamma and ICC are ignored. `decodePng` does not check the size limits, so call `pngSize` and check the limits before the full decode. Failures are `CoreError` `not-an-image` or `decode-failed`. `encodePng` is deterministic and not optimized: the optimized file comes from [[PRIMITIVES#encodeImage]].
  Consumers: 3 (`core/handlers/decode.ts`, `core/encode/png.ts`, `core/encode/ico.ts`).
- **`FORMAT_INFO` / `EXPORT_FORMATS`**, `src/core/formats.ts`, confirmed
  The static facts of each export format: extension, MIME, label, lossless, alpha and largest side. Contract: `FORMAT_INFO: Record<ExportFormat, { ext; mime; label; lossless; alpha; maxSide }>`; `EXPORT_FORMATS: readonly ExportFormat[]` (the order of the export dialog); `ExportFormat` lives in `core/types.ts`. Each `maxSide` is the format limit, not the document limit, and [[PRIMITIVES#fitsFormat]] enforces it. The JPEG extension is `jpg`. The values are in the file.
  Consumers: 5 (`app/platform.ts`, `app/state.svelte.ts`, `core/encode/limits.ts`, `ui/StatusBar.svelte`, `ui/dialogs/ExportDialog.svelte`).
- **`resizeRaster`**, `src/core/resample.ts`, confirmed
  The one high-quality resampler of `RasterImage`. Contract: `resizeRaster(src, width, height, method: ResampleMethod, { onProgress?(ratio) }?): RasterImage`, with `ResampleMethod = 'auto' | 'smooth' | 'sharp' | 'nearest'` in `core/types.ts`. `sharp` is Lanczos3, `smooth` is Mitchell-Netravali, and `auto` selects per axis: Lanczos to shrink, Mitchell to grow. The filters work on premultiplied alpha, so transparent pixels do not darken the edges and keep RGB 0. The function always returns a new raster, also at the same size. It throws `CoreError('internal')` for a size that is not a whole number of 1 or more, and for a bad source. It does not check the size limits, and it is synchronous. Main-thread code calls it through `ImageEngine.resize` ([[PRIMITIVES#ImageEngine]]), never directly. Its kernel constants live in `PARAMS.resample`.
  Consumers: 3 (`core/handlers/resize.ts`, `core/handlers/adjust.ts`, `core/encode/ico.ts`).
- **`PARAMS`**, `src/core/params/index.ts`, confirmed
  The one home of every algorithm constant, with one section for each feature file in `src/core/params/`. The values are in the files.
  Consumers: 29 (`app/actions/geometry.ts`, `app/actions/paint.ts`, `app/aspect.ts`, `app/estimate.svelte.ts`, `app/history.svelte.ts`, `app/state.svelte.ts`, `app/text-render.ts`, `app/tools/brush.ts`, six `core/adjust/*`, four `core/encode/*`, `core/handlers/adjust.ts`, `core/handlers/decode.ts`, `core/handlers/export.ts`, `core/mask.ts`, `core/resample.ts`, `ui/dialogs/ExportDialog.svelte`, `ui/dialogs/NewImageDialog.svelte`, `ui/options/PaintOptions.svelte`, `ui/overlays/brush-cursor.ts`, `ui/panels/Levels.svelte`, `ui/panels/Sharpen.svelte`).

## worker bridge

- **`EngineRequest` / `EngineReply` / `Handler` / `AdjustSession`**, `src/core/protocol.ts`, confirmed
  The typed message contract between the main thread and the engine worker. Contract: `EngineRequest` (union on `type`: `decode`, `adjust-begin`, `adjust-preview`, `adjust-commit`, `adjust-end`, `vignette`, `resize`, `estimate`, `export`, each with `id`); `EngineReply` (`{ id, ok: true, type, ... }` for each type, or `{ id, ok: false, error: ErrorCode, detail? }`); `EngineEvent { id, type: 'progress', ratio }`; `RequestFor<T>`, `ReplyFor<T>`; `Handler<T> = (request, context: HandlerContext) => HandlerResult<T> | Promise<...>`; `HandlerResult { reply /* without id and ok */, transfer? }`; `HandlerContext { id, progress(ratio), session }`; `AdjustSession`, `createAdjustSession()`, `resetAdjustSession(session)`. The `adjust-*` requests share state in one worker: `adjust-begin` fills the session, and `adjust-end` clears it. The begin mask is at document size, and `offset` is the layer position. A preview `region` is in layer px, and `null` means a proxy of the whole layer. A new request type needs a member in both unions, a [[PRIMITIVES#HANDLERS]] entry and an [[PRIMITIVES#ImageEngine]] method. The worker transfers the image buffers of a reply, so the receiver owns them.
  Consumers: 7 (`app/engine.ts`, `core/worker.ts`, `core/handlers/adjust.ts`, `core/handlers/decode.ts`, `core/handlers/export.ts`, `core/handlers/resize.ts`, `core/handlers/index.ts`).
- **`HANDLERS`**, `src/core/handlers/index.ts`, confirmed
  The worker-side registry with one handler for each request type, which the worker loop of `src/core/worker.ts` dispatches. Contract: `HANDLERS: { [T in RequestType]: Handler<T> }`. The mapped type stops the build when a request type has no handler. The list is in the file. One worker module serves both engine lanes. Each worker runs its requests one at a time, in arrival order, so a long request blocks all later requests in its lane. Each worker instance has one `AdjustSession`. The worker clamps progress ratios to 0..1. A throw becomes `{ ok: false, error: errorCode(error), detail }` ([[PRIMITIVES#CoreError]]), and an unknown type becomes `internal`.
  Consumers: 1 (`core/worker.ts`).
- **`ImageEngine` / `EngineError`**, `src/app/engine.ts`, confirmed
  The only door from the main thread to the workers: two lazy worker lanes, transfer-safe copies, and stale-call control. Contract: `onProgress(listener): () => void`; `decode(bytes: ArrayBuffer, name): Promise<{ image; format }>`; `adjustBegin(image, mask | null, offset): Promise<Histogram>`; `adjustPreview(op, region | null): Promise<{ image; rect; scale } | null>`; `adjustCommit(op): Promise<RasterImage>`; `adjustEnd(): Promise<void>`; `vignette(w, h, params): Promise<RasterImage | null>`; `resize(image, w, h, method): Promise<RasterImage>`; `estimate(image, options): Promise<{ plainBytes; bytes } | null>`; `exportImage(image, options): Promise<{ bytes: Uint8Array; plainBytes }>`; `dispose()`; `EngineError { code: ErrorCode; detail }`. Lane `fast` runs decode, adjust, vignette and resize. Lane `codec` runs estimate and export. Each worker starts on the first request of its lane. The engine copies each image and mask before the transfer, so the caller keeps its own. `decode` transfers `bytes`, so the caller loses them. `adjustPreview`, `vignette` and `estimate` are "latest wins": a stale call resolves `null`, and the caller must drop that result. `adjustBegin`, `adjustCommit` and `adjustEnd` make all earlier previews stale. A newer estimate restarts the codec worker, because the encoders cannot stop. `exportImage` also restarts a running estimate. During an export, only the newest estimate waits. The progress listeners get the ratios of all open requests in both lanes, not of one call. A worker crash rejects each open request with `internal` and loses the adjust session. The app keeps one instance as `app.engine` ([[PRIMITIVES#app]]).
  Consumers: 8 (constructed in `app/state.svelte.ts`; called from `app/state.svelte.ts`, `app/estimate.svelte.ts`, `app/generators.ts`, `app/tools/move.ts`, `ui/dialogs/ExportDialog.svelte`, `ui/dialogs/ImageSizeDialog.svelte`, `ui/panels/AdjustPanel.svelte`, `ui/panels/Vignette.svelte`).

- **`History` / `HistoryEntry`**, `src/app/history.svelte.ts`, confirmed
  Undo and redo stacks with a memory budget, coalesce and a dirty flag that ignores changes outside the exported image. Contract: `HistoryEntry { label: TextKey; bytes: number; coalesce?: string; neutral?: boolean; undo(); redo() }`; `push(entry)`, `undo(): HistoryEntry | null`, `redo(): HistoryEntry | null`, `markClean()`, `clear()`, reactive getters `canUndo`, `canRedo`, `dirty`, `undoLabel`, `redoLabel`, `bytes`. `push` clears redo. Two entries with the same `coalesce` key inside `TUNING.ui.coalesceMs` merge into one step, and the label of the step is the label of its newest part. A `neutral` entry is an undo step but does not make the document dirty. `clear()` keeps a dirty document dirty. When the stacks go above `PARAMS.history.budgetBytes` or `maxSteps`, the oldest steps drop, but the newest step always stays. `bytes` must count the pixel copies that the entry keeps, or the budget is wrong. Only `EditorDoc` makes and pushes entries. Other code reads `doc.history` and must call `doc.undo()` / `doc.redo()`, never `doc.history.undo()`, because that skips the change event of the document.
